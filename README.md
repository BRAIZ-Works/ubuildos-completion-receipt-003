A lightweight, dependency-free browser tool for turning meeting notes into owned, dated actions with deterministic overdue status and local CSV export.

## Run it
Open `index.html` in a modern browser.

## Storage and network behavior
- Data persists only in browser `localStorage`.
- The application makes no network calls.
- It does not send email, write calendars, assign tasks in external systems, or perform autonomous external actions.
- Included sample data is synthetic/public-demo data.
