# START HERE — Meeting Action Tracker™ v1.0.0

1. Open `index.html` in a modern browser, or serve this folder with `python -m http.server`.
2. Use the synthetic sample board or add a new action with action text, owner, and due date.
3. Edit, complete/reopen, and export actions from the board.
4. Overdue means: **incomplete** and `due_date < today's local date`.
5. `Reset sample` restores the original synthetic fixture.

Data stays in browser `localStorage`. The product makes no network calls and performs no email, calendar, task-system, or other external writes.
