Meeting Action Tracker™

Turn meeting notes into owned, dated actions—without pretending the tool can email, assign, or update external systems for you.

Local by designNo network calls. Sample data only. Browser localStorage persistence.

What this is

A small accountability tool for turning a meeting handoff into explicit actions with an owner, due date, status, overdue signal, and CSV export.

What this is not

It does not send emails, write calendars, assign tasks in external systems, or use private customer data. It makes no autonomous external changes.

Quick guide

  1. Create an action with action text, owner, and due date.
  2. Edit any action without changing its stable ID.
  3. Complete or reopen actions as work changes.
  4. An incomplete action is overdue when its due date is earlier than today.
  5. Export the current action set as CSV; the file is generated in your browser.
  6. Reset restores the original synthetic sample data.

Data behavior: data is stored only in this browser's localStorage. No network or external service is used by the product.

Measured evidence

Producer tests cover create, edit, complete/reopen logic, overdue boundaries, stable identity, invalid inputs, CSV generation, security/privacy/no-network checks, and static accessibility/readability checks. Human live-browser review remains a separate gate.

UBuildOS value

This release shows the method around the product: locked scope, explicit requirements, evidence-bound QA, Safe-Change repair when a claim defect is found, and separate Fresh IQA, owner, and publication gates.
